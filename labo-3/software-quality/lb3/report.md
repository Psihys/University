## Test Design

### 1. calculateDiscount

Для тестування функції `calculateDiscount()` було обрано такі тестові умови та тестові дані:

| Test Condition | Test Data | Expected Result |
|---|---|---|
| Звичайна знижка 10% | price = 100, percent = 10 | 90 |
| Відсутність знижки | price = 100, percent = 0 | 100 |
| Повна знижка 100% | price = 100, percent = 100 | 0 |
| Від'ємна ціна | price = -10, percent = 10 | Помилка |

Тести перевіряють правильність розрахунку знижки, граничні значення відсотка знижки та обробку некоректної ціни.

### 2. validateQuantity

Для функції `validateQuantity()` застосовано метод еквівалентних класів (Equivalence Partitioning) та аналіз граничних значень (Boundary Value Analysis).

**Еквівалентні класи:**

| Клас | Значення | Expected Result |
|---|---|---|
| Допустимі цілі числа | Від 1 до 10 включно | `true` |
| Значення нижче мінімуму | 0 | `false` |
| Значення вище максимуму | 11 | `false` |
| Дробові числа | 1.5 | `false` |

**Граничні значення:**

| Значення | Призначення | Expected Result |
|---|---|---|
| 0 | Нижче мінімальної межі | `false` |
| 1 | Мінімальне допустиме значення | `true` |
| 10 | Максимальне допустиме значення | `true` |
| 11 | Вище максимальної межі | `false` |

Додатково перевірено значення 2 і 9 для підтвердження правильності обробки значень усередині допустимого діапазону.

### 3. getShippingCost

Для функції `getShippingCost()` перевірено основні гілки виконання програми:

| Test Condition | Test Data | Expected Result |
|---|---|---|
| Від'ємна сума замовлення | total = -1 | Помилка |
| Сума менша за 1000 | total = 999 | 100 |
| Сума дорівнює порогу безкоштовної доставки | total = 1000 | 0 |

Тестування підтверджує, що функція повертає помилку для від'ємної суми, встановлює вартість доставки 100 для замовлень до 1000 та забезпечує безкоштовну доставку для замовлень на суму 1000 або більше.
